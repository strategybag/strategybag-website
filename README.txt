STRATEGY BAG HEADER-ONLY FIX
============================

This package changes ONLY the top navigation + hero.

FILES
-----
index.html
styles.css
strategy-bag-logo.jpg
rocket-hero-right.png

HOW TO USE WITH YOUR EXISTING SITE
----------------------------------
1. Back up your current repository.
2. Copy the <header> and <section class="hero"> blocks from this index.html
   into your existing index.html, replacing only your current header/hero.
3. Copy the CSS rules from this styles.css into your current styles.css,
   replacing only the existing header/hero rules.
4. Upload rocket-hero-right.png and strategy-bag-logo.jpg to the same folder
   as index.html, OR update the paths if you prefer a subfolder.
5. Commit and publish through GitHub Pages.
6. Hard refresh with Ctrl+F5.

IMPORTANT
---------
The navigation, headline, supporting text and buttons are real HTML/CSS.
Only the right-side rocket artwork is an image.
